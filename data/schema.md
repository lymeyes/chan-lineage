# 祖师数据 Schema（data/patriarchs/\<id\>.yaml）

每位祖师一份 YAML，文件名即 `id`，必须与 `lineage.json` 中的节点 `id` 一致，
站点才能把分支图节点与该人的生平/引文对应上。

## 字段定义

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 与 `lineage.json` 节点 id 完全一致（如 `临济义玄禅师`）。**规则：标准通行法名 + 原称谓后缀**，不带任何前缀（无 `L::`/`ROOT::`/`PRE::`），不用灯录省称（`百丈海`、`马祖一`）、不带驻地名与谥号 |
| `name` | 是 | 显示名（如 `临济义玄`）。与 `id` 去称谓后缀后应一致 |
| `alias` | 否 | 别号别名，顿号分隔（如 `天童华`、`昭觉克勤`、`超觉大师`）。驻地名 / 庵号 / 谥号 / 灯录省称一律放这里，**不进文件名** |
| `honorific` | 否 | 尊号 / 谥号 / 世称（如 `临济祖师`、`大鉴禅师`） |
| `school` | 否 | 所属宗派（临济宗 / 曹洞宗 / 云门宗 / 法眼宗 / 沩仰宗 / 黄龙派 / 杨岐派） |
| `dynasty` | 否 | 朝代（如 `唐`） |
| `birth_death` | 否 | 生卒年（据传，存疑标 `?`） |
| `region` | 否 | 驻锡地 / 弘化地（如 `镇州临济院`） |
| `teacher` | 否 | 师承（`lineage.json` 中的父节点 id 或人名） |
| `students` | 否 | 重要弟子 id 列表 |
| `source_ref` | 是 | 首要出处，精确到卷与条（如 `五灯会元·卷十一·临济义玄禅师`） |
| `bio` | 否 | 生平叙述。**必须据灯录原文转述，不得臆造**；可注明存疑处 |
| `sayings` | 否 | 代表公案 / 语录 / 偈颂列表，每项：`text`（原文）+ `ref`（精确出处） |
| `status` | 是 | `core`（核心，已填实并校核）/ `draft`（已填内容，待 CBETA 逐字校核——默认起点）/ `named_only`（在所校灯录中未获独立条目，仅存谱系名位）。`sample` 为早期样例，已弃用 |
| `verify_status` | 是（`draft` 卡） | 校核层级，四档互斥，**不可混看**：`line_verified`（已回原文逐字对校）> `sourced`（人工摘录并核过出处）> `extracted`（机器从原文条目批量抽取，内容确出正典但未经人工逐字校订）> `anchor_only`（仅有典籍锚点，无正文摘录） |
| `verify` | 否 | 校对付注：记录待核对项 / 已知异文 / 节点名称与标准名差异等 |
| `cbeta` | 否 | CBETA 电子佛典对应册号 / 经号（便于溯源） |

## 校对工作流（draft → core）

本库默认 **`draft` 起步、校核后升 `core`**：

1. 新人填卡先标 `status: draft`，内容据灯录转述并填 `ref`。
2. 逐字比对 CBETA 电子佛典后，确认无错漏，改 `status: core`，并在 `verify` 留痕。
3. 灯录未载事迹者，宁可 `named_only` 也**不臆造**。

## 学术诚信规则（强制）

1. **每条 `sayings[].text` 必须来自权威底本（灯录 / 大正藏 / 中华藏），并填 `ref`。**
2. **不得编造生平或公案。** 灯录未载者，留空或标 `status: named_only`，不可脑补。
3. 古籍本身属公版；CBETA 数字化版本按 CC 授权转载并**署名来源**。
4. 存疑记载（如「拈花微笑」之史源性）须在 `bio` 内显式说明，不混入定论。

## 示例（节选）

```yaml
id: 临济义玄禅师
name: 临济义玄
alias: 临济玄 / 慧照禅师
honorific: 临济祖师
school: 临济宗
dynasty: 唐
region: 镇州临济院
teacher: 黄檗希运
source_ref: 五灯会元·卷十一·临济义玄禅师
verify_status: line_verified
status: draft
sayings:
  - text: "佛法无用功处，只是平常无事……"
    ref: 五灯会元·卷十一
```
